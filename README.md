# Sheilla Mumbi Macharia — Portfolio

Personal portfolio site for Sheilla Mumbi Macharia, a data science practitioner building predictive models, automated reporting pipelines, and AI-powered tools across health, retail, telecom, agriculture, and creative services.

**Live site:** [sheilamumbi.github.io/sheillamacharia.github.io](https://sheilamumbi.github.io/sheillamacharia.github.io/)

## Features

- Single-page layout: About, Skills, Tech Stack, Projects, Education, Resume, Contact
- Interactive **Tech Stack** section — click a technology chip to filter and jump to the project(s) it was actually used in
- Scrollspy navigation with a working mobile menu
- Scroll-reveal animations, respecting `prefers-reduced-motion`
- [`cv.html`](cv.html) — an HTML/CSS résumé styled to match the site, exportable to PDF via the browser's print dialog

## Tech Stack

Vanilla HTML, CSS, and JavaScript — no build step, no dependencies. Fonts loaded from Google Fonts (Space Grotesk, DM Sans).

## Structure

```
index.html                  Portfolio site
cv.html                      Standalone HTML résumé (print/export to PDF)
Sheilla_Macharia_CV.pdf      Exported PDF résumé, linked from the site
Sheilla_Macharia.jpeg        Profile photo
```

## Running locally

No build tools required — open [index.html](index.html) directly in a browser, or serve the folder with any static file server.
